# 📝 Word Frequency Analyzer with Visualization

This Python project takes user input (a sentence or paragraph), analyzes the word frequency, and visualizes the results using a bar chart. 
It's a great beginner-friendly project that combines Python basics, data cleaning, and simple data visualization — a mini taste of Natural Language Processing (NLP) and Exploratory Data Analysis (EDA)!

---

## 🚀 Features

- Takes user input as a string of text
- Converts all text to lowercase for accurate counting
- Removes punctuation to avoid false duplicates (e.g., "python." ≠ "python")
- Splits text into words
- Counts the frequency of each word
- Displays total word count
- Visualizes word frequencies with a bar chart using Matplotlib

---

## 🛠️ Technologies Used

- Python 3.x
- Matplotlib (for plotting)
- String module (for punctuation cleaning)
